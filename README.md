# portal-cn-notes

本仓库用于归档和发布多个独立的 HTML 页面。这些页面以静态文件的形式存放，可直接通过 GitHub Pages 或本地浏览器访问。

## 项目简介

这是一个轻量级的 HTML 页面集合仓库。每个页面均为独立、自包含的 HTML 文件，不依赖后端服务或特定域名。仓库的主要目的是方便页面内容的集中管理、版本记录与分享。

## 目录说明

```
portal-cn-notes/
├── index.html          # 仓库入口页面（可选）
├── pages/              # 存放各独立 HTML 页面的目录
│   ├── page-1.html
│   ├── page-2.html
│   └── ...
├── assets/             # 公共资源文件夹（样式、脚本、图片等）
│   ├── css/
│   ├── js/
│   └── images/
└── README.md           # 本文件
```

- `index.html`：可选的仓库首页，用于导航或展示页面列表。
- `pages/`：核心内容目录，每个 HTML 文件代表一个独立的归档页面。
- `assets/`：存放页面共享的静态资源，如样式表、JavaScript 脚本和图片。

## 页面归档说明

- 每个 HTML 页面均为独立文件，可脱离仓库环境直接运行。
- 页面之间的链接建议使用相对路径，以便在本地或部署后保持可用。
- 页面内容遵循通用 HTML 规范，无特殊技术要求。
- 归档内容以静态形式保存，不涉及动态数据或外部接口。

## 维护说明

- 新增页面：在 `pages/` 目录下创建新的 HTML 文件，并确保引用资源路径正确。
- 更新页面：直接编辑对应 HTML 文件，提交后自动更新归档版本。
- 删除页面：移除对应文件，并更新 `index.html`（如有）中的链接。
- 建议在提交时附带简要的 commit 信息，说明新增、修改或删除的内容。

## 使用方式

1. 克隆或下载本仓库到本地。
2. 直接在浏览器中打开 `pages/` 下的任一 HTML 文件。
3. 若启用 GitHub Pages，仓库根目录下的 `index.html` 将作为默认入口。

## 注意事项

- 本仓库不存储任何敏感信息或私密数据。
- 页面内容仅供归档参考，不构成任何形式的承诺或保证。
- 如有疑问或建议，欢迎提交 Issue 或 Pull Request。
